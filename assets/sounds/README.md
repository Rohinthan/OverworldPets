# Custom Sounds Guide

You can add your own custom sound effects to OverworldPets by placing audio files in this folder.

### Supported File Formats
`.mp3`, `.wav`, or `.ogg`

### Recognized File Names
* `touch.mp3` - Plays when you click or catch the pet.
* `rub.mp3` - Plays when you pet/stroke the mascot with your cursor.
* `happy.mp3` - Plays when the mascot enters happy mode (winks & spins).
* `throw.mp3` - Plays when you fling the mascot across the screen.

*Note: Sound files placed in this folder are automatically excluded by `.gitignore` to protect personal custom assets.*
